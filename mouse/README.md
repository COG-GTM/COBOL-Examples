# Mouse Example

This is a very simple example drawing program created to demonstrate the mouse functionality and how to use it.

## How to Compile

```bash
cobc -x mouse_example.cbl
```

## How to Run

```bash
./mouse_example
```

The program enters screen mode and allows you to draw on the terminal using mouse clicks.

![Image of paint program with hello world written](https://i.imgur.com/6zq1Kia.png)

## Prerequisites

- GnuCOBOL (`cobc`)
- A terminal that supports ncurses and mouse events
- Interactive (requires mouse input)
